L2 模組層-Gems

打造固定風格的助教

Gems 封裝特定 Prompt 與知識庫，適合固定格式、重複性產出，例如依教學風格生成學習單。

原稿操作路徑

把期待寫進指令

4. Gems vs Skill

Gems 與 Skill 的決定性差異

示意｜學習目標：能依工作需求比較 Gems 與 Skill，說明選擇理由。

比較工作方式

教材以 Persona 與 Workflow 比較兩者：Gems 透過系統指令與知識庫設定角色及語氣；Skill 透過結構化參數、程序與檢核封裝專業方法。

比較優點與限制

Gems 設定直覺、富有彈性與創意，但複雜格式可能遺漏規則。Skill 需要清楚的參數與結構化思考；透過結構化步驟與檢核提高一致性，產出仍須確認。

教師選擇指南

潤飾聯絡簿、情境故事等工作，可考慮 Gems；雙向細目表、Rubrics 或跨模組教材流程，可考慮 Skill。原稿也提出在 Gem 中喚醒 Skill 的協作方式。

比較項目GemsSkill
核心Persona：角色與語氣Workflow：程序與檢核
設定白話系統指令、知識庫參數、結構化步驟
適用文字風格、情境故事矩陣、教案與跨模組流程
提醒複雜限制可能遺漏產出仍須確認

6. 自動化中樞島

L5 系統層-Workspace

示意｜學習目標：能辨識觸發條件與後續動作，畫出教學行政工作流。

讓事件啟動工作流

Workspace 在原稿中是跨服務的教學行政整合中樞。透過事件觸發後續動作，串起收件、分析、紀錄與回饋。

原稿流程範例

Google Form 提交 → 呼叫 Gemini API 分析簡答 → 將評分內容寫入 Google Docs → 透過 Gmail 寄發回饋。這是教材介紹的外部工作流，本站僅供學習，不會代為串接或寄信。

原稿限制與評閱向度

原稿記載每帳號 25 個工作流、每工作流 20 個步驟。評閱範例以概念精確度、批判思辨力、實例佐證力、素養實踐力、邏輯表達力五向度，每項 20 分、共 100 分分析作答。

教材提示詞

[角色任務]
  你現在是一位深耕教育評量與媒體識讀專業的「AI 閱卷評閱專家」。你的目標是針對學生的簡答題作答，提供客觀、精準且具教育啟發性的結構化評量。

  [背景資訊]
  學生剛完成以「AI與媒體識讀」為主題的簡答題測驗。我們需要透過五大核心向度來衡量學生的資訊素養與AI認知，以確保他們具備在數位時代辨識真偽的能力。

  [具體指令]
  請閱讀以下學生的作答內容，並嚴格依照下列五個向度（每個向度滿分20分，總計100分）進行計分與深度分析：
  1. 概念精確度（20分）：評估對AI術語與運作機制的理解正確性。
  2. 批判思辨力（20分）：評估分析AI生成內容潛在風險與偏見的能力。
  3. 實例佐證力（20分）：評估使用具體案例支持自身觀點的能力。
  4. 素養實踐力（20分）：評估提出的事實查核步驟或防範策略是否具體可行。
  5. 邏輯表達力（20分）：評估文意通順度與論述結構的嚴謹性。

  針對學生的作答，請產出以下回覆：
  - 【總分評定】：給出總分（/100）。
  - 【雷達圖分析】：列出五個向度的個別得分。
  - 【優勢與亮點】：具體點出作答中表現最優異的1至2個面向。
  - 【成長鷹架】：針對失分項目，提出具體且可操作的改善建議。

  [約束條件]
  1. 必須一律使用繁體中文與臺灣教育用語回覆。

7. 任務 vs Studio

進階架構比較

示意｜學習目標：能區分單次主動產出與事件自動化，安排適用的教學階段。

主動產出與事件觸發

Spark（任務）由老師在備課時主動喚醒，處理當次素材；Workspace Studio 則依設定的事件啟動後續流程。

比較成果與階段

Spark 重點是多模態教材打包與歸檔，適合課前備課；Workspace Studio 重點是資料流轉與派發，適合課中、課後作業處理。

把兩種引擎接起來

先以任務將文本轉成教案、簡報與題庫，再規劃學生提交後的分析、紀錄與回饋流程。依需求選擇工具，把時間留給教學中的溫度與關懷。

比較項目Spark（任務）Workspace Studio
啟動主動喚醒式、時間週期式事件觸發式
目的教材打包與歸檔資料流轉與派發
階段課前備課課中與課後
範例文本 → 文件、簡報與題庫收件 → 分析 → 紀錄 → 寄信
